Паттерны для распознования метода решения:

- Скользящее окно (Sliding Window):
  1. **"Фиксированный размер k"** → два указателя на фиксированном расстоянии
  2. **"Максимальная/минимальная длина с условием"** → динамическое окно (правый расширяет, левый сужает)
  3. **"Подсчет количества подмассивов/подстрок"** → окно + комбинаторика
  4. **"Бонус/штраф за предыдущие элементы"** → окно-состояние (история)
  5. **"Поиск анаграммы/перестановки"** → окно фиксированной длины + частотный словарь

- Метод указателей (Ponters):
  1. **"Найти пару"** → два указателя с разных сторон
  2. **"Палиндром"** → два указателя с разных сторон (частный случай поиска пары)
  3. **"Удалить дубликаты"** → два указателя с одной стороны
  4. **"Цикл/середина списка"** → быстрый и медленный
  5. **"Слияние массивов"** → два указателя на разных массивах

- Стек (Stack):
  1. **«Парные элементы / Скобки»** → Стек для хранения открывающих элементов.
  2. **«Отмена действия / Возврат к предыдущему состоянию»** → Стек для хранения истории.
  3. **«Монотонный стек» (поиск следующего большего/меньшего элемента)** → Стек для хранения индексов/значений в возрастающем/убывающем порядке.
  4. **«Обратная польская нотация (RPN)» / Калькулятор** → Стек для операндов.
  5. **«Обход дерева в глубину (DFS) без рекурсии»** → Стек для хранения узлов для посещения.

- Рекурсия (Recursion):
  1. **"Задачи, которые можно разбить на подзадачи"** → всё, что связано с деревьями (поиск, обход).
  2. **"Backtracking (Поиск с возвратом)"** → нужно перебрать все возможные комбинации/пути (лабиринты, расстановка ферзей).
  3. **"Разделяй и властвуй (Divide & Conquer)"** → данные делятся на части, каждая решается рекурсивно, затем результаты сливаются (сортировка, бинарный поиск).
  4. **"Построение всех возможных последовательностей"** → генерация перестановок, комбинаций, подмножеств.
  5. **"Динамическое программирование (сверху вниз)"** → рекурсия + мемоизация (кэширование) для оптимизации

- Бинарный поиск (Binary Search):
  1. **"Поиск в отсортированном массиве"** → Нужно найти число или проверить наличие.
  2. **"Поиск границы (First/Last Position)"** → Ищем не любое вхождение, а самое левое (первое) или самое правое (последнее).
  3. **"Поиск в почти отсортированном массиве"** → Массив изначально отсортирован, но затем сдвинут (ротирован).
  4. **"Поиск ответа (Binary Search on Answer)"** → Мы **подбираем ответ** (число), проверяя, выполняется ли некоторое условие.
  5. **"Поиск пика (Peak)"** → Поиск элемента, который больше своих соседей.

- Деревья (Trees):
  1. **"Поиск в глубину (DFS)"** → рекурсивный обход (preorder/inorder/postorder)
  2. **"Поиск в ширину (BFS)"** → уровень за уровнем с использованием очереди
  3. **"Проверка свойств BST"** → использование диапазонов (min/max)
  4. **"Построение дерева"** → из обходов (preorder+inorder) или из списка
  5. **"Пути в дереве"** → накопление суммы/пути от корня до листьев
  6. **"Модификация структуры"** → инвертирование, балансировка, привязка указателей

- Графы (Graphs):
  1. **"Связность компонент / Поиск пути"** → DFS (поиск в глубину)
  2. **"Кратчайший путь в невзвешенном графе"** → BFS (поиск в ширину)
  3. **"Топологическая сортировка / Зависимости"** → DFS или Алгоритм Кана (на основе степеней входа)
  4. **"Кратчайший путь во взвешенном графе"** → Алгоритм Дейкстры
  5. **"Отрицательные веса / Поиск всех путей"** → Алгоритм Беллмана-Форда
  6. **"Все пары вершин / Плотные графы"** → Алгоритм Флойда-Уоршелла
  7. **"Минимальное остовное дерево (МОД)"** → Алгоритмы Прима или Краскала
  8. **"Сильно связанные компоненты (ССК)"** → Алгоритм Косарайю или Тарьяна
  9. **"Задачи на сетках (2D матрицы)"** → DFS / BFS с проверкой соседей

- Жадные алгоритмы (greedy algorithm):
  1. **"Найти минимальное/максимальное количество X"** → часто требует сортировки и выбора "самого подходящего" первым.
  2. **Задачи на интервалы** (расписания, покрытия) → классика для жадных алгоритмов.
  3. **Задачи на монеты/деньги** (стандартными номиналами) → бери самую большую монету.
  4. **Задачи с приоритетом** (всегда делай самое "дорогое" или самое "дешевое" задание).
  5. **Задачи, где можно доказать, что "обмен" (exchange argument) не ухудшает решение**.

- Динамическое программирование (Dynamic Programming):
  1. **"Количество способов / Лестница"** → Задачи, где нужно посчитать количество уникальных способов достичь цели (например, подняться по лестнице, добраться до точки).
  2. **"Наибольшая/Наименьшая сумма/путь"** → Задачи оптимизации, где нужно выбрать путь или набор предметов, максимизирующий или минимизирующий некоторую величину (например, задача о рюкзаке, треугольник).
  3. **"Динамика на строках / Последовательностях"** → Задачи сравнения двух строк (наибольшая общая подпоследовательность, расстояние Левенштейна) или поиска палиндромов.
  4. **"Домашнее ограбление / Соседи"** → Задачи, где выбор текущего элемента запрещает выбор соседних.
  5. **"Биткоин / Акции"** → Задачи на оптимизацию с состояниями (например, есть/нет акции в портфеле).

- Хеш таблица (Hash Table):
  1. **"Поиск отсутствующего/повторяющегося"** → подсчет частот через хеш-таблицу
  2. **"Проверка на наличие пары/комплемента"** → сохранение просмотренных элементов для мгновенного поиска "напарника"
  3. **"Группировка элементов по свойству"** → использование сложных ключей для объединения данных (анаграммы, суммы и т.д.)
  4. **"Кэширование результатов" (Мемоизация)** → сохранение результатов дорогостоящих вычислений для повторного использования
  5. **"Поиск пересечений/различий"** → быстрое определение общих или уникальных элементов между коллекциями

- Префиксные хеши (Prefix Hash):
  1. **"Сумма подмассива"** → префиксная сумма (самый частый случай)
  2. **"Равенство нулю/единице/букве"** → префиксная сумма для баланса (замена 0/1 или подсчет символов)
  3. **"Подмассив с условием на XOR"** → префиксный XOR
  4. **"Количество подмассивов с условием"** → префиксная сумма + хеш-таблица (счетчик)
  5. **"Произведение подмассива"** → префиксное произведение (осторожно с нулями и переполнением)

- Теория чисел (Number Theory):
  1. **Проверка на простоту / Разложение на множители** → Перебор до √n, решето Эратосфена.
  2. **НОД (наибольший общий делитель)** → Алгоритм Евклида (O(log n)). Используется для сокращения дробей, проверки взаимной простоты, задач на деление.
  3. **Делимость и остатки** → Свойства модулярной арифметики.
  4. **Работа с факториалами** → Предподсчёт для быстрых вычислений.
  5. **Работа с цифрами числа** → Выделение цифр через `% 10` и `/ 10`.

- Алгоритмы на строках (String Algorithms):
  1. **"Анаграмма / Учет частот"** → Подсчет символов (массив на 26)
  2. **"Подстрока / Подпоследовательность"** → Два указателя / Скользящее окно
  3. **"Палиндром"** → Два указателя с концов или расширение от центра (уже есть в методе указателей, но здесь это ключевая тема)
  4. **"Поиск паттерна"** → Префиксное дерево (Trie) или алгоритм Кнута-Морриса-Пратта (КМП)
  5. **"Динамика по строке"** → Динамическое программирование (двумерный массив)
